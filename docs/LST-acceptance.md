- 静态网站使用 Pyodide 执行原 Python 规则，不能把它说成 GitHub 提供了 FastAPI 后台。
- S001–S003 / T001 是本机演示身份；本机身份分开显示，但源码/存储可被访问者查看，不是保密或跨设备身份系统。
