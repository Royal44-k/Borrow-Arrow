# V1.6 验收范围与实际限制

本轮是三维草船、分阵箭雨和相关剧情的有限升级。原版本、原始素材、生产存档和论文文档保留。最终发布与数据库核验以release.json、qa/production.json为准。

## 已实现

- 原创可旋转/缩放的实几何船体：厚船板、帆面褶皱、绳索、草束、青布、灯笼、舵橹；木材使用本地CC0颜色/法线/粗糙度贴图。整备为单船，出航/转舷为二十船队。空船开始，工具可鼠标拖放，也可键盘操作。
- 试射、第一阵与第二阵有不同密度和落点。近景箭经过视野，接箭与落水区分；第一阵落一舷，转船后另一舷才受第二阵。敲鼓产生声效，暂停/略过只控制表现，不给箭数或能力加分。
- 16个新剧情节点，23幅本轮独立原创场景，按前情和天气选图；渐入、缓慢镜头运动、水面和雾光动效。图片不是23段连续演员影片。
- 试射后撤、先收一舷、转船后静听、近寨被疑停射、佯动后收船、搭箭后撤令等相互衔接。靠岸、点人船、卸草把、拔样箭、两舷核数及三人后续保留。
- 台词按人物和语句匹配固定自然语音；哨长使用成年男声。文案审查后去除“镜头随箭”“不能把张弓算作已射”等后台说明，以及船上未经清点先知五万/十万的反复报数。

## 仍需如实区分

当前模型有重复草束和程序化水纹，材质、光照、船队运动、人物连续表演与参考视频仍有艺术品质差距。软件通过不能证明“视觉效果完全一致”。无专业演员连续视频、无精确流体/战争仿真、无全设备帧率结论。

真实DeepSeek按用户要求暂停，本轮调用0。固定TTS不是实时数字人。教学目标映射与事件记录不构成素养提升或诊断有效性的证明；没有虚构教师、学生或问卷结果。火攻/盔甲诱饵等更早讨论过的扩展没有因本轮而全部实现，不作虚假交付宣称。

文学顺序依据《三国演义》第46回的选段；新增停射/佯动等是本课原创推演。参考视频与动效站的实际观察范围见research-notes.md，未把联系表采样称逐帧遍历全片。
